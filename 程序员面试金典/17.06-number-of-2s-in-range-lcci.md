## 核心思路：数位分析法

假设我们想知道在百位上，数字 2 出现了多少次。我们可以把当前的数字 $n$ 拆成三个部分：

- `high`（当前位左边的最高位部分）

- `cur`（当前位上的数字）

- `low`（当前位右边的最低位部分）

以当前位为百位（`digit = 100`）为例，根据 `cur` 的不同，百位上出现 2 的次数可以分为 3 种情况：

| **当前位数字 cur** | **规律与公式**                                                                    | **举个例子（假设看百位，digit=100）**                                                                                                               |
| ------------------ | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`cur < 2`**      | 2 出现的次数完全由高位决定：<br><br> <br><br>`high * digit`                       | $n = 1123$，百位是 1。百位要出现 2，高位只能是 0。所以只有 `0200 ~ 0299` 这 100 个数，即 `0 * 100 = 0` 次。                                         |
| **`cur == 2`**     | 高位决定了基础次数，低位决定了剩余次数：<br><br> <br><br>`high * digit + low + 1` | $n = 1234$，百位是 2。高位取 0 时有 `0200~0299`（100个）；高位取 1 时，受低位限制，只能取 `1200 ~ 1234`（35个）。总共 `1 * 100 + 34 + 1 = 135` 次。 |
| **`cur > 2`**      | 2 出现的次数完全被高位“填满”了：<br><br> <br><br>`(high + 1) * digit`             | $n = 1323$，百位是 3。高位可以取 0 和 1。也就是 `0200 ~ 0299` 和 `1200 ~ 1299` 全都能取满。总共 `(1 + 1) * 100 = 200` 次。                          |

### 优化后的 Java 代码

我们用一重循环，让 `digit` 每次乘以 10（个位 $\rightarrow$ 十位 $\rightarrow$ 百位 $\rightarrow$ ...），直到超过 $n$ 为止：

```Java
class Solution {
    public int numberOf2sInRange(int n) {
        int res = 0;
        long digit = 1; // 用 long 防止 digit * 10 的时候超出 int 范围

        // 从个位开始，一位一位往上计算
        while (n / digit > 0) {
            long high = n / (digit * 10);
            long cur = (n / digit) % 10;
            long low = n % digit;

            // 根据当前位数字的大小，应用上面表格中的三种数学规律
            if (cur < 2) {
                res += high * digit;
            } else if (cur == 2) {
                res += high * digit + low + 1;
            } else {
                res += (high + 1) * digit;
            }

            // 移动到下一位（个位 -> 十位 -> 百位...）
            digit *= 10;
        }

        return res;
    }
}
```

### 为什么这个解法这么快？

> **复杂度对比：**
>
> - **你的暴力解法：** 需要走 $n$ 次大循环，里面还要把数字转字符串再遍历，总操作次数约 $559,366,752 \times 9 \approx 50$ 亿次。
> - **数位分析解法：** 因为 $n \le 10^9$，数字最多 10 位，`while` 循环最多跑 **10 次**。无论 $n$ 是几亿还是几十亿，都是微秒级瞬间秒杀！
